# Workflow core

Workflow memories define repository procedures that must be read before the
corresponding action.

- Before creating a commit, read
  [`creating-commits.md`](creating-commits.md). It defines message format,
  validation, AI attribution, and amend permissions.
- Before verifying UI, accessibility, responsiveness or Lighthouse, read
  [`web-verification.md`](web-verification.md). It defines server reuse, preview
  isolation, commands, viewports, thresholds and reporting.
