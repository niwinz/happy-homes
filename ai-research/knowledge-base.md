The best way to work with Claude right now is this...

When you start a new project (SaaS, content, app, whatever it is), do this:

Open a brand-new chat with Opus 4.8. Turn on Extended Thinking and pour out everything you know about your project—don't skip a thing.

Then write this:

"ask me 5 questions that would help you have a complete understanding of this project"

Give detailed answers to these questions. Spend a good amount of time here—DON'T RUSH IT.

Once you've finished your answers, paste this:

"you're my co-founder. create a master plan with a knowledge base directory for each section. attach context markdown files to every part. you're building the skeleton that Claude Code will use to build everything 10x faster. suggest skills to integrate, automations to build or any tool that’d 10x our speed. suggest when to use a project or Claude Code"

Claude will pull together the entire skeleton of your project, folder structure, and files. Import it directly into Claude Code.

Now you're building your project together with it. You're using regular Claude like a chat, but in a much more powerful way.

Claude will tell you when to open Claude Projects, which research to dive deeper into, and which MCPs to use. A single planning session like this is worth weeks of grinding on your own.

That's how you build projects with AI.
